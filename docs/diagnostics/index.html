How the test was run

Question
Given NESO's morning WINDFOR vintage and open ECMWF weather, can TabPFN-3.5 issue a better forecast of tomorrow's hourly GB wind, fifteen minutes later?
Target
Available transmission wind: metered FUELHH output plus curtailment paid for in the Balancing Mechanism (BOAV), hour-ending means. WINDFOR forecasts output before curtailment, so this is its like-for-like target.
Inputs
ECMWF IFS 0.25° 100 m wind at 20 capacity-weighted points, turned into power-curve capacity factors and wind direction; installed capacity, lead, hour, season; and the WINDFOR value for the hour. Only the newest weather run public before WINDFOR is used.
Model
TabPFN-3.5 via tabpfn-client, no training or tuning: each month it is handed every hour settled at least a day before issue as context and predicts capacity factor deciles. The median is the point forecast.
Test
Code
windpfn/model.py, 03_test.ipynb, protocol in docs/method.md. Page data built by scripts/diagnostics.py.
